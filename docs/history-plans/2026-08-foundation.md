# 历史规划：Core 基础能力

状态：已完成并归档。

## 规划目标

建立统一 Agent、Task/Execution/Run Registry、会话作用域、权限收窄、消息基础和 Workflow/Community 核心骨架。

## 已完成结果

- Agent 支持默认创建、角色模板和真实会话分支；global/project/session 作用域可区分。
- Task、Execution 和 Run Registry 保存状态、成本、PID、heartbeat、终态和父谱系。
- 权限从角色模板到实例再到单次运行逐层收窄。
- Workflow、Community 和 Message V2 核心状态机已形成。
- TUI Workbench、命令、工具和基础回收能力已接入。

## 归档原因

基础规划的主要目标已完成，剩余问题已拆分到当前主题规划，不再在本文件继续追加任务。
